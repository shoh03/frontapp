# 커뮤니티 피드 — 화면 명세

| 항목 | 값 |
|---|---|
| 화면 | 커뮤니티 피드 |
| 경로 | `/community` |
| 디자인 소스 | `community.png` (1920×1080) |
| 작업 범위 | 헤더를 제외한 본문 전체 |
| 최종 수정 | 2026-11-25 |

---

## 1. 목표와 맥락

헤더의 "커뮤니티"를 눌렀을 때 나오는 화면이다.

임산부·육아맘·보호자가 게시글을 훑어보고 상세로 진입하는 것이 목적이다. 글을 빠르게 스캔하고, 관심 카테고리로 좁히고, 원하는 글로 들어가는 흐름이 가장 중요하다.

---

## 2. 기술 스택과 환경

| 항목 | 값 |
|---|---|
| 프레임워크 | Next.js (App Router) |
| 언어 | TypeScript |
| UI | React 19 |
| 스타일링 | Tailwind CSS v4 |
| 데이터 패칭 | **미정 — 14번 확인 필요** |
| 상태관리 | **미정 — 14번 확인 필요** |

목록은 클라이언트 컴포넌트로 구현한다. 검색 디바운스, 스크롤 추가 로딩, 정렬·카테고리 전환이 모두 클라이언트 상호작용이기 때문이다. 페이지 셸(레이아웃, 정적 영역)은 서버 컴포넌트로 둔다.

---

## 3. 기존 코드베이스 규칙

- `/app/community/` 안의 코드 전체를 먼저 읽고, 그 패턴을 따른다.
- 폴더 구조, 파일 네이밍, 컴포넌트 작성 방식, import 순서 모두 기존 코드 기준.
- 이미 있는 공통 컴포넌트가 있으면 새로 만들지 말고 재사용한다.
- 기존 패턴과 이 문서가 충돌하면 **이 문서가 우선**이며, 충돌 사실을 보고한다.

## 8. 기능과 인터랙션

### 상단

| 동작 | 조건 | 결과 |
|---|---|---|
| [+ 이야기 나누기] 클릭 | 로그인 상태 | `/communitpost` 로 이동 |
| [+ 이야기 나누기] 클릭 | 비로그인 | `/login?redirect=/communitpost` 로 이동 |

버튼은 비로그인 상태에서도 동일하게 노출된다. 숨기거나 비활성화하지 않는다.
로그인 성공 후에는 `redirect` 파라미터의 경로로 이동시킨다.

### 좌측 패널 — 검색

| 동작 | 조건 | 결과 |
|---|---|---|
| 검색어 입력 | 1자 이상 | 입력 300ms 후 제목 부분일치로 목록 갱신, 페이지는 1로 초기화 |
| 검색어 입력 | 공백만 입력 | 요청 보내지 않음, 직전 목록 유지 |
| 검색어 전체 삭제 | — | 검색 해제, 현재 선택된 카테고리 기준 목록으로 복귀 |

검색은 **제목만** 대상으로 한다. 본문·작성자는 검색하지 않는다.
검색과 카테고리는 **AND 조건**으로 함께 적용된다.

### 좌측 패널 — 카테고리

전체 피드 / 임신 이야기 / 육아 이야기 / 우리 동네 / 건강·병원 / 살림·추천

| 동작 | 조건 | 결과 |
|---|---|---|
| 항목 클릭 | 비선택 상태 | 해당 카테고리 글만 출력, 페이지 1로 초기화, 정렬 탭은 유지 |
| 항목 클릭 | 이미 선택됨 | 아무 변화 없음 (전체 피드로 해제되지 않음) |
| 선택 표시 | — | 배경 `--brand-subtle`, 텍스트 `--brand-text` Bold, 우측 `›` 노출 |
| 호버 | 비선택 항목 | 배경 `--surface-alt` |

최초 진입 시 "전체 피드" 선택 상태.
각 항목 왼쪽에는 카테고리 식별 색 점(6×6)을 표시하고, 항목 사이에 1px `--border` 구분선을 둔다.

### 좌측 패널 — 가입 유도 배너

| 동작 | 조건 | 결과 |
|---|---|---|
| 배너 영역 클릭 | 비로그인 | `/login` 으로 이동 |
| 배너 영역 클릭 | 로그인 상태 | 배너 자체를 렌더하지 않음 |

카드 전체가 클릭 영역이다. "가입하고 둘러보기 →" 텍스트만이 아니다.

### 중앙 — 정렬 탭

| 동작 | 조건 | 결과 |
|---|---|---|
| [인기글] 클릭 | — | 조회수 내림차순 정렬, 페이지 1로 초기화, 카테고리·검색어 유지 |
| [최신글] 클릭 | — | 작성일 내림차순 정렬, 페이지 1로 초기화, 카테고리·검색어 유지 |
| 선택 표시 | — | 텍스트 `--text` Bold + 하단 2px `--brand-text` 바, 비선택은 `--muted-light` |

최초 진입 시 "인기글" 선택 상태.

### 중앙 — 게시글 카드

| 동작 | 조건 | 결과 |
|---|---|---|
| 카드 클릭 | 항상 | `/communitview` 로 이동 |
| 제목 1줄 초과 | — | 1줄에서 말줄임 |
| 썸네일 없음 | — | 썸네일 영역을 렌더하지 않고 본문 영역이 그만큼 넓어짐 |

좋아요·댓글 수는 **표시 전용**이다. 이 화면에서는 클릭해도 동작하지 않는다.

### 중앙 — 목록 로딩과 페이지네이션

한 페이지는 게시글 **10개**다.

| 동작 | 조건 | 결과 |
|---|---|---|
| 최초 진입 | — | 상위 5개 렌더 |
| 아래로 스크롤 | 목록 하단 도달, 현재 페이지에 남은 글 있음 | 다음 5개를 이어서 로드 (최대 10개) |
| 아래로 스크롤 | 현재 페이지 10개 모두 출력됨 | 추가 로딩 없음, 페이지네이션으로 이동해야 함 |
| 페이지 번호 클릭 | 다른 페이지 | 해당 페이지 상위 5개 렌더, 목록 최상단으로 스크롤 |
| 페이지 번호 클릭 | 현재 페이지 | 아무 변화 없음 |
| `‹` `›` 클릭 | 이전/다음 페이지 있음 | 해당 페이지로 이동 |
| `‹` `›` 클릭 | 첫/마지막 페이지 | 비활성 처리, 클릭 불가 |

### 레이아웃 동작

| 동작 | 조건 | 결과 |
|---|---|---|
| 중앙 목록 스크롤 | 항상 | 좌측 패널(검색·카테고리·배너)과 우측 패널이 화면에 고정되어 함께 따라옴 |
| 패널 높이 > 뷰포트 | — | 해당 패널은 자체 스크롤, 중앙 목록과 독립 동작 |

좌·우 패널은 `position: sticky`, 상단 오프셋은 헤더 높이 80px + 24px.

### 우측 패널 — 오늘의 인기상품

| 동작 | 조건 | 결과 |
|---|---|---|
| [더보기 →] 클릭 | 항상 | `/shop` 으로 이동 |
| 상품 행 클릭 | 항상 | 동작 없음 (이번 범위 아님) |

"오늘의 한마디"는 정적 노출이며 상호작용이 없다.

### 상태

| 상태 | 조건 | 화면 |
|---|---|---|
| 최초 로딩 | 진입, 카테고리·탭·페이지 변경 | 카드 스켈레톤 5개. 좌·우 패널은 그대로 유지 |
| 추가 로딩 | 스크롤로 다음 5개 로드 중 | 목록 하단에 스켈레톤 카드, 기존 카드는 유지 |
| 검색 중 | 디바운스 후 요청 진행 | 목록 영역만 스켈레톤, 검색창 입력값은 유지 |
| 빈 상태 (카테고리) | 해당 카테고리 글 0건 | "아직 글이 없어요" + [이야기 나누기] 버튼 |
| 빈 상태 (검색) | 검색 결과 0건 | "'{검색어}' 검색 결과가 없어요" + [검색 지우기] 버튼 |
| 에러 | 목록 요청 실패 | "불러오지 못했어요" + [다시 시도] 버튼. 좌·우 패널은 정상 노출 |

### 범위 밖 (이번에 만들지 않음)

- 게시글 작성 폼 (`/communitpost` 이동까지만)
- 게시글 상세 (`/communitview` 이동까지만)
- 로그인 화면 자체 (`/login` 이동까지만, `redirect` 파라미터 처리는 로그인 화면 담당)
- 좋아요·댓글 실제 동작 (숫자 표시만)
- 인기상품 개별 행 클릭
- 헤더 전체

## 10. 반응형

**이번 범위는 Desktop 1920 고정이다.** 모바일·태블릿 대응은 하지 않는다.

| 조건 | 동작 |
|---|---|
| 뷰포트 ≥ 1920 | 콘텐츠 1320 고정, 좌우 여백 자동 분배 (가운데 정렬) |

Tailwind 반응형 접두사(`sm:` `md:` `lg:`)를 임의로 붙이지 않는다. 위 3가지 외의 분기를 만들지 않는다.

## 11. 접근성

### 시맨틱 구조

| 영역 | 태그 |
|---|---|
| 좌측 패널 | `<aside>` + `aria-label="카테고리 및 검색"` |
| 중앙 목록 | `<main>` |
| 우측 패널 | `<aside>` + `aria-label="추천 정보"` |
| 게시글 목록 | `<ul>` / `<li>` |
| 페이지네이션 | `<nav aria-label="페이지 이동">` |

### 키보드

- 게시글 카드는 `<a>` 또는 `<button>`으로 구현한다. `<div onClick>` 금지.
- 모든 상호작용 요소는 Tab으로 접근 가능해야 한다.
- 포커스 링을 `outline: none`으로 지우지 않는다. 디자인에 포커스 상태가 없으면 `--brand-text` 2px 링을 사용한다.
- 탭 순서: 이야기 나누기 → 검색 → 카테고리 → 배너 → 정렬 탭 → 게시글 목록 → 페이지네이션 → 우측 패널

### 스크린리더

- 정렬 탭은 `role="tablist"` / `role="tab"` + `aria-selected`.
- 선택된 카테고리는 `aria-current="true"`.
- 썸네일이 장식용이면 `alt=""`, 의미가 있으면 게시글 제목을 `alt`로 쓴다.
- 좋아요·댓글 숫자에는 `aria-label="좋아요 42개"`처럼 단위를 붙인다.
- 로딩 중에는 목록 컨테이너에 `aria-busy="true"`.
- 검색 결과 건수 변화는 `aria-live="polite"` 영역으로 알린다.

### 대비

- 본문 `--text`(#27313A) 대 흰 배경: 통과.
- `--muted-light`(#9AA4AA)는 **12px 이하 본문에 쓰지 않는다.** 대비가 부족하다. 기준 시각·비활성 탭 등 보조 정보에만 사용한다.
- 할인율 `--sale`(#E0808F)은 Bold 12px 이상에서만 사용한다.
